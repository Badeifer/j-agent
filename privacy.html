Privacy policy

J-Agent. Last updated October 8, 2026.

Who uses this app

J-Agent is a personal tool. Its only user is its developer, who signs in with his own Google account. It is not offered to the public.

What Google data it accesses

  • Gmail, read only (gmail.readonly): message headers, snippets and bodies, used to sort incoming mail into categories the user defines.
  • Google Calendar, read only (calendar.readonly): event titles, times and locations for the next two weeks, used to show an agenda.

The app never sends, edits, labels or deletes email, and never creates, edits or deletes calendar events.

How the data is used and stored

Data is processed on the user's own computer. Sorted results are saved as files on that computer. Sign-in tokens are stored on that computer outside any synced folder. Calendar attendee addresses and event descriptions are not stored.

Sharing

Google user data is not sold, shared with third parties, used for advertising, or used to train generalized AI or machine learning models. The app's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Removing access

Access can be removed at any time at myaccount.google.com/permissions. Deleting the app's folder on the computer removes the stored results.

Contact

Questions: use the support email shown on the Google sign-in screen for this app.
