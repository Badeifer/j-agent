Privacy policy

J-Agent. Last updated October 13, 2026.

Who uses this app

J-Agent is a personal tool. Its only user is its developer, who signs in with his own Google account. It is not offered to the public.

What Google data it accesses

  • Gmail, read only (gmail.readonly): message headers, snippets and body text, used to sort incoming mail into categories the user defines. Body text is read by fixed rules on the user's computer, for example to find a date, and then discarded.
  • Gmail drafts (gmail.drafts.create): the app can save a draft the user asked for into his Drafts folder. It never sends mail.
  • Google Calendar events (calendar.events): it reads event titles, times and locations for the next two weeks to show an agenda, and it creates, updates and removes events on one calendar the user names, only events the app itself created, with the user's confirmation. An event can carry one invitee address the user has chosen in the app's settings.

The app never sends, edits, labels or deletes email, and never changes events it did not create.

How the data is used and stored

Data is processed on the user's own computer. To sort mail, the sender, subject and a short snippet of each message are sent to an AI model (Anthropic's Claude) through the user's own account; message bodies are not sent. Calendar event titles and times are sent the same way to write his daily summary. Sorted results are saved as files on that computer, and those files may be backed up to the user's private source-control repository. Sign-in tokens are stored on that computer outside any synced folder. Calendar attendee addresses and event descriptions from other people's events are not stored.

Sharing

Google user data is not sold, not used for advertising, not shared with anyone except Anthropic as described above, and not used to train generalized AI or machine learning models. The app's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Removing access

Access can be removed at any time at myaccount.google.com/permissions. Deleting the app's folder on the computer removes the stored results.

Contact

Questions: use the support email shown on the Google sign-in screen for this app.
